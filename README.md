# TaskBolt Landing Page

Modern, lightning-fast landing page for TaskBolt - automation services for local service businesses.

## Features

- ⚡ Built with Next.js 15 + TypeScript
- 🎨 Styled with Tailwind CSS
- 🎭 Smooth animations with Framer Motion
- 📱 Fully responsive design
- ⚡ Lightning bolt theme with electric blue & yellow
- 🚀 Optimized for performance

## Getting Started

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build for Production

```bash
npm run build
npm start
```

## Deploy to Vercel

1. Push this code to GitHub
2. Go to [vercel.com](https://vercel.com)
3. Import your GitHub repository
4. Vercel will auto-detect Next.js and deploy
5. Connect your taskbolt.com domain in Vercel settings

## Sections

- **Hero** - Eye-catching intro with lightning bolt animation
- **Features** - What TaskBolt automates
- **How It Works** - 4-step process
- **CTA** - Call-to-action with stats
- **Contact** - Lead capture form
- **Footer** - Company info and links

## Customization

### Colors

Edit `tailwind.config.ts` to change the color scheme:
- `navy`: Dark background colors
- `electric.blue`: Primary accent (#00d4ff)
- `electric.yellow`: Secondary accent (#ffd60a)

### Content

Edit components in the `/components` folder to update text and content.
